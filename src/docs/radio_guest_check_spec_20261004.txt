ラジオ ゲスト情報チェック(バッチ版) 仕様 (2026-10-04)
=====================================================

■ 概要
  inbox/archive/cowork_radio_guest_check.md(Cowork で手動実行していた手順)をバッチ化したもの。
  radiko / NHKラジオ(らじる★らじる)/ 音泉 のゲスト出演情報を Grok で調べ、
  Claude でまとめてメールで通知する。
  本体: modules/radio_guest_check.py(Grok 操作は modules/grok_web.py を共用)

■ Cowork版からの変更点
  ・対象期間: 実行日から5日分(本日〜4日後)  ※Cowork版は10日後まで
  ・頻度: 3日に1回、13:00 に実行(22:30・06:30 の Xトレンド取得と Grok が被らないように)
  ・Grok は grok.com(grok_web 経由)。毎回新しい会話で質問するため、
    「同じスレッドで言い換え質問」はできない。言い換え検索は、元の質問に
    「公式X・本人/事務所の投稿も確認して」を加えた独立した質問として送る
  ・マージ(radiko リスト外2セットの統合・フォロー中番組との重複除去・整形)は
    最後に claude -p を1回呼んで行う。失敗時は取得結果を機械的に並べる

■ 実行タイミング
  ・毎日 13:00 に起動(土日含む)
  ・前回成功日から 3 日以上たっていれば実行(例: 10/4 → 10/7 → 10/10 ...)
  ・Grok が1問も成功しなかった場合は「成功」と記録しないので、翌日 13:00 に再実行

■ Grok への質問(最大8問、この順で実行)
  1. radiko フォロー中番組(番組リストを名指し)
  2. radiko フォロー中番組(言い換え: 公式X・本人/事務所投稿も確認)
  3. NHKラジオ(音楽・バラエティ。ミュージックラインの本放送/再放送、
     らじらー！サンデー等の定期特番も確認するよう指示)
  4. 音泉
  5〜6. radiko リスト外 セットA(本体・言い換え)
  7〜8. radiko リスト外 セットB(本体・言い換え)
  ・Grok の利用上限(grok_web の設定: 2時間で10問)に達したらそこで打ち切り、
    それまでの結果でまとめる(優先度の高い順に並べてある)
  ・各回答から Claude が「番組名・放送局・放送日・放送時間・ゲスト・聴けるURL」を
    抜き出す(ゲスト出演ありのみ。URL は radiko ライブ/タイムフリー、
    らじる★らじる、onsen.ag を優先し、リンクの実URLを確認する)

■ まとめの形式(Cowork版のルール8と同じ)
  【radiko】
  ■ フォロー中番組
  10/6(火) 番組名／放送局 25:00
  ゲスト: ○○
  URL: https://radiko.jp/#!/live/...

  ■ リスト外
  ...
  【NHKラジオ】
  【音泉】
  ・放送日の早い順。複数放送日は日ごとに分ける
  ・フォロー中番組とリスト外で重複したものはフォロー中番組側だけに載せる
  ・0件の見出しは省く。「該当なし」「ゲスト情報なし」、情報源の注記は書かない
  ・対象期間外の放送日は除く

■ 出力(メールのみ)
  ・結果はメールで通知する。テキストファイルは保存しない
    (Cowork版の「output フォルダに radio_guest_YYYYMMDD_HHMM.txt を保存」は廃止)
  ・成功・失敗にかかわらず、実行した回は必ずメールする
      件名「ラジオ ゲスト情報 M/D〜M/D」           … すべて成功
      件名「【一部失敗】ラジオ ゲスト情報 M/D〜M/D」 … 一部の検索が失敗(成功分でまとめる)
      件名「【失敗】ラジオ ゲスト情報 M/D〜M/D」     … Grok がすべて失敗(翌日 13:00 に再実行)
  ・本文: まとめたゲスト情報 → 末尾に「検索結果(Grok n/8件成功)」として
    8問それぞれの成否(成功なら件数、失敗ならエラー内容)
  ・Claude でのまとめに失敗した場合は、その旨の注意書き+取得結果をそのまま並べる
  ・内部記録: output/radio_guest_check.json(直近の結果)、
    state/radio_guest_check_state.json(前回成功日)

■ 設定(config.json の radio_guest_check)
  interval_days      : 3    何日おきに実行するか
  days_ahead         : 4    本日から何日後までを対象にするか(4 = 5日分)
  followed_programs  : フォロー中の番組リスト(「番組名／放送局 放送時間」形式)
                       リストを更新するときはここを書き換える

■ 手動実行
  前提: Chrome 起動中・Claude in Chrome 拡張が接続済み・grok.com にログイン済み
    cd src
    .venv\Scripts\python.exe -m modules.radio_guest_check --force
  ※ --force は「3日おき」の判定だけをスキップする(Grok の利用上限チェックは有効)

■ 注意
  ・Grok の回答は回ごとにブレる(Cowork版の経緯参照)。網羅は100%保証しない
  ・1回の実行で Claude セッションを最大9回起動する(Grok 8問+まとめ1回)
  ・取りこぼしや形式の不満は、都度改善を依頼する運用
