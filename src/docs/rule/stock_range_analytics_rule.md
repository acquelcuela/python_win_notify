# 30日レンジ スコアリング 判断ルール(2026-08-20時点)

385件(評価済み全件・2026-07-27〜08-19、18取引日分)の考察を、今後の判断基準として
まとめたもの。詳細な数字の根拠は`stock_range_hitrate_snapshot_20260820.md`を参照。
件数が増えたら都度この内容を見直す前提。

## 確立ルール(統計的に裏付けあり、p<0.05)

1. **レンジ位置80〜90%(高値圏)は弱シグナルとして扱う**
   的中率25.9%(n=27, p=0.011)。momentumスコアが現状「レンジ上位70%以上」に
   加点しているロジックとは向きが逆。この帯の候補はスコアが高くても割り引いて見る。

2. **レンジ位置10〜20%(押し目)は強シグナルとして扱う**
   的中率77.8%(n=18, p=0.047)。他の帯より明確に良い。

## 保留ルール(まだ動くべきタイミングではない、件数不足)

3. **スコアの点数自体は優先順位付けの根拠にしない**
   40点台〜80点台まで的中率47〜55%でフラット(全バンドp≥0.4)。スコアが高い
   候補を優先する意味は、今のログでは確認できていない。

4. **銘柄単位の当たり外れは判断材料にしない**
   NVDA以外、37銘柄すべてp≥0.05で「偶然の範囲」。IHI(27%)やテクニスコ(74%)の
   ような目立つ数字も、今の件数(各銘柄5〜23件)ではまだ根拠として使えない。
   目安: 各銘柄30件を超えてから再検証する。

5. **地合い連動ロジック(2026-08-11導入の`_market_adjustment`)の効果は未確認**
   むしろmomentum型は変更後にやや悪化(54.0%→50.3%、n=137→161)。改善したとは
   言えない状態。ロジックを戻すかは判断保留、継続観察。
