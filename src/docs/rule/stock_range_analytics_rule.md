# 30日レンジ スコアリング 判断ルール(2026-08-20時点)

385件(評価済み全件・2026-07-27〜08-19、18取引日分)の考察を、今後の判断基準として
まとめたもの。詳細な数字の根拠は`stock_range_hitrate_snapshot_20260820.md`を参照。
件数が増えたら都度この内容を見直す前提。

## 確立ルール(統計的に裏付けあり、p<0.05)

1. **レンジ位置80〜90%(高値圏)は弱シグナルとして扱う**
   的中率25.9%(n=27, p=0.011)。momentumスコアが現状「レンジ上位70%以上」に
   加点しているロジックとは向きが逆。この帯の候補はスコアが高くても割り引いて見る。

2. **レンジ位置10〜20%(押し目)は強シグナルとして扱う**
   的中率77.8%(n=18, p=0.047)。他の帯より明確に良い。

## 保留ルール(まだ動くべきタイミングではない、件数不足)

3. **スコアの点数自体は優先順位付けの根拠にしない**
   40点台〜80点台まで的中率47〜55%でフラット(全バンドp≥0.4)。スコアが高い
   候補を優先する意味は、今のログでは確認できていない。

4. **銘柄単位の当たり外れは判断材料にしない**
   NVDA以外、37銘柄すべてp≥0.05で「偶然の範囲」。IHI(27%)やテクニスコ(74%)の
   ような目立つ数字も、今の件数(各銘柄5〜23件)ではまだ根拠として使えない。
   目安: 各銘柄30件を超えてから再検証する。

5. **地合い連動ロジック(2026-08-11導入の`_market_adjustment`)の効果は未確認**
   むしろmomentum型は変更後にやや悪化(54.0%→50.3%、n=137→161)。改善したとは
   言えない状態。ロジックを戻すかは判断保留、継続観察。

## 特別注目銘柄(⭐金色カード)の選出ルール(2026-10-02〜、試験運用)

メインレポートの「30日レンジ 本日の上昇候補」で、過去の成績が良い銘柄を金色で
強調表示する仕組み。判定は`modules/report_html.py`の`_special_watch_tickers()`が
レポート生成のたびに`state/stock_range_predictions.json`から自動計算する
(手作業の登録・解除は不要。成績次第で自動で入れ替わる)。

- **現在の基準**: 同じ型(モメンタム/リバーサル)で**10回以上**評価済み、かつ
  その型での的中率が**50%超**
  - 定数 `SPECIAL_WATCH_MIN_N = 10` / `SPECIAL_WATCH_HIT_RATE_PCT = 50.0`
  - モメンタム型とリバーサル型は別々に数える(例: 住友電工はリバーサル81%、
    モメンタム57%と型で成績が違うため)
- **表示条件**: その日の候補(各型上位5件)に出た銘柄だけが金色になる。基準を
  満たしていても候補に出なければ表示されない
- **バッジ**: 「⭐特別注目 的中9/11(82%)」のように回数と率を表示

### 基準の見直し(月1回程度)

毎月、次のウォークフォワード検証で基準を調整する:
各日について「その前日までのデータだけ」で基準を当てはめ、選ばれた銘柄の
その日以降の的中率を、選ばれなかった銘柄と比べる。差が出なくなったら基準を
変える(回数を増やす・的中率を上げる等)。

### 経緯

| 日付 | 基準 | 該当数 | 検証結果 |
|---|---|---|---|
| 2026-09-17 | n≥8・的中率65%超(両型合算) | 6銘柄 | 偶然でも約5.4銘柄が該当する水準。選出後53.7% vs その他51.6%でほぼ差なし |
| 2026-10-02 | n≥20・型別・二項検定p<0.05 | 0件 | 厳しすぎて該当なし(最有力はシチズン モメンタム18/28、p=0.107) |
| 2026-10-02 | **n≥10・型別・的中率50%超(現行)** | 17/32件 | 選出後57.8%(89/154) vs その他50.3%。差は出たがまだ偶然の可能性あり。60%超・65%超の方が成績が低く、基準と成績が比例していない点に注意 |

注意: 型別の平均的中率がモメンタム50.8%・リバーサル55.3%(2026-10-02時点)
なので、「50%超」はほぼ「平均以上」の意味。保留ルール4(銘柄単位の当たり外れは
判断材料にしない)は引き続き有効で、特別注目は**目立たせる表示のみ**、スコアには
反映しない。

## 地合い別の表示(2026-10-06〜)

「当日プラスで終わったか」の的中率は、ほぼ当日の地合いで決まっていた(50営業日・774件):
日経平均・TOPIX(連動ETF 1306で代用)が両方上昇した日はモメンタム64%・リバーサル72%、
両方下落した日は29%・27%。全体の約52%は、この2つを平均しただけの数字だった。
スコアの点数帯にも単調な傾向はなく(40点台43%〜60点台56%〜80点台46%)、
日経平均との比較でも勝率は約50%で、銘柄選びの優位性は確認できていない。

そこでレポートでは、単一の的中率の代わりに次を出す(`report_html.py`):
- 地合い別の的中率(型ごと、両方上昇/まちまち/両方下落)
- 今日の見込み的中率 = 今朝の夜間先物と同じ水準だった過去の朝の「地合いの比率」×地合い別の的中率
  (同じ水準の朝が5日未満なら、全期間の地合いの比率で代用)
- 各候補カードに、その銘柄の地合い別の実績と「下げの日にも強い」「相場次第」のラベル
  (上昇日・下落日とも4日以上あるときだけ。強い=上昇日60%以上かつ下落日50%以上、
  相場次第=上昇日70%以上かつ下落日20%以下)

06:45の「時間外の動き」(スコアの地合い補正と見込み的中率に使う)は、2026-10-06から
Yahoo!リアルタイム検索で「日経時間外」の最新の投稿(3時間以内・最大5件の中央値)を読み、
Yahoo!ファイナンスのトップページの前日終値と比べて計算する(`modules/market_realtime.py`)。
投稿が取れないときは従来のCME先物(NKD=F)。それより前の記録はCME先物の値なので、
先物の水準別の集計には2つのソースが混在している点に注意。
当日の地合いの判定も、Yahoo!ファイナンスのトップページ(本物のTOPIX)を優先し、取れなければyfinance。

当日の地合い(`market_day`)は `stock_range_eval` が大引け後の最終判定で記録し、
過去分(2026-10-06以前)は日次データから自動で埋めた(評価日が祝日になっていた8/11・9/22・9/23の29件は、その日の指数データがないため不明のまま)。

## Xトレンド銘柄の目印(2026-10-06〜)

Xトレンド銘柄(`stock_x_trends`、255件・37営業日)の検証結果:
- 「前日終値→終値」では日経平均に60%勝っていたが、大半は寄り付き前の値の飛び(平均+2.1%)。
  **寄り付きで買って大引けで売ると、全体では日経平均に勝った47%で優位性なし**
- 話題の種類で差: positive(材料系)57% / strong_positive(「爆上げ確定」系)41%
- 寄り付きで+3%以上値が飛んだ銘柄は32%(その日のうちに下げやすい)
- positive かつ 値の飛び+3%未満が最良: 60%(89件)。まだ偶然の範囲を抜けきっていない

レポートの「Xトレンド銘柄」欄に目印を出す(`report_html.py` の `_x_trend_badge`):
◎=positive かつ 値の飛び+3%未満 / ⚠=strong_positive / ⚠=値の飛び+3%以上(09:00以降のレポートのみ)。
表示する数字は固定値なので、件数が増えたら検証し直して更新する。

## 売買タイミングの目安(2026-10-06〜)

ユーザーの売買パターン(朝イチで買って10時までに売る/15時までに売る)に合わせて、
1時間足で検証した(2026-08〜10の48営業日、30日レンジ候補708件+Xトレンド銘柄237件。
寄り付き=9時台の始値、10時=9時台の終値、15時=14時台の終値で代用)。

- 寄り付き直後の1時間は弱い。どの種類も10時時点のプラスは5割未満になりがち
- ほとんどの種類で「10時で売る」より「15時まで持つ」方が成績がよい
- 寄り付きで買った場合、10時にプラスなら79%がプラスのまま15時に終わる(Xの材料系は94%)。
  10時にマイナスなら15時にプラスへ戻るのは25%(煽り系はさらに下げる)
- 10時に買う→15時は、寄り付きで買う→15時よりよい(全体55% vs 49%、モメンタム57% vs 48%)。
  ただし日経平均に勝った割合は約50%で、相場全体の後場の戻り(日経平均の10時→15時は平均+0.15%)が大きい。
  日経平均が最初の1時間で0.5%以上下げた日は、15日中11日で15時までに戻した
- Xの材料系(positive)は寄り付きで買う方がよい(65% vs 10時買い62%)。
  煽り系・寄り付きで+3%以上値が飛んだ銘柄は、どのタイミングでも優位性なし

買う時刻は15分足でも比較した(8/10〜10/6の38営業日・703件、9:00〜12:30の8通り×15時売り):
- 寄り付きちょうど(9:00)はモメンタム型(48%)と煽り系(39%、平均-0.55%)で最も不利。
  15分待つだけで改善する(全体50%→53%、煽り系の損失-0.55%→-0.19%)
- 9:15〜10:00の間に大きな差はない(9:45が特別よいわけではない)。モメンタム型は10:00が最良(54%)
- Xの材料系は9:00が最良(67%、平均+0.98%)で、待つほど利幅が減る(11:00買いは+0.38%)
- 煽り系はどの時刻に買っても41〜48%で勝てない

レポートの30日レンジ欄とXトレンド欄に「売買タイミングの目安」として表示する(数字は固定値)。
上げ相場の約2か月分のデータなので、下げ相場の期間を含めて見直す。
