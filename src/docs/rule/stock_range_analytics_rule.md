まとめたもの。詳細な数字の根拠は`stock_range_hitrate_snapshot_20260820.md`を参照。
件数が増えたら都度この内容を見直す前提。

## 撤回したルール(2026-11-06)

8/20に「確立ルール」としていた次の2つは、ルール作成後のデータ(8/20〜11/4)で再現しなかったため撤回した。
考察やレポートの判断材料には使わない。

1. ~~レンジ位置80〜90%(高値圏)は弱シグナル~~
   作成時 25.9%(n=27, p=0.011) → 作成後のデータでは **63.3%(n=49)** と逆に良い
2. ~~レンジ位置10〜20%(押し目)は強シグナル~~

新しいルールは「作った後のデータ」で確かめてから確立扱いにする。

## 地合い別の表示(2026-10-06〜)

「当日プラスで終わったか」の的中率は、ほぼ当日の地合いで決まっていた(50営業日・774件):
日経平均・TOPIX(連動ETF 1306で代用)が両方上昇した日はモメンタム64%・リバーサル72%、
両方下落した日は29%・27%。全体の約52%は、この2つを平均しただけの数字だった。
スコアの点数帯にも単調な傾向はなく(40点台43%〜60点台56%〜80点台46%)、
日経平均との比較でも勝率は約50%で、銘柄選びの優位性は確認できていない。

そこでレポートでは、単一の的中率の代わりに次を出す(`report_html.py`):
- 地合い別の的中率(型ごと、両方上昇/まちまち/両方下落)
- 今日の見込み的中率 = 今朝の夜間先物と同じ水準だった過去の朝の「地合いの比率」×地合い別の的中率
  (同じ水準の朝が5日未満なら、全期間の地合いの比率で代用)
- 各候補カードに、その銘柄の地合い別の実績と「下げの日にも強い」「相場次第」のラベル
  (上昇日・下落日とも4日以上あるときだけ。強い=上昇日60%以上かつ下落日50%以上、
  相場次第=上昇日70%以上かつ下落日20%以下)

06:45の「時間外の動き」(スコアの地合い補正と見込み的中率に使う)は、2026-10-06から
Yahoo!リアルタイム検索で「日経時間外」の最新の投稿(3時間以内・最大5件の中央値)を読み、
Yahoo!ファイナンスのトップページの前日終値と比べて計算する(`modules/market_realtime.py`)。
投稿が取れないときは従来のCME先物(NKD=F)。それより前の記録はCME先物の値なので、
先物の水準別の集計には2つのソースが混在している点に注意。
当日の地合いの判定も、Yahoo!ファイナンスのトップページ(本物のTOPIX)を優先し、取れなければyfinance。

当日の地合い(`market_day`)は `stock_range_eval` が大引け後の最終判定で記録し、
過去分(2026-10-06以前)は日次データから自動で埋めた(評価日が祝日になっていた8/11・9/22・9/23の29件は、その日の指数データがないため不明のまま)。

## Xトレンド銘柄の目印(2026-10-06〜)

Xトレンド銘柄(`stock_x_trends`、255件・37営業日)の検証結果:
- 「前日終値→終値」では日経平均に60%勝っていたが、大半は寄り付き前の値の飛び(平均+2.1%)。
  **寄り付きで買って大引けで売ると、全体では日経平均に勝った47%で優位性なし**
- 話題の種類で差: positive(材料系)57% / strong_positive(「爆上げ確定」系)41%
- 寄り付きで+3%以上値が飛んだ銘柄は32%(その日のうちに下げやすい)
- positive かつ 値の飛び+3%未満が最良: 60%(89件)。まだ偶然の範囲を抜けきっていない

レポートの「Xトレンド銘柄」欄に目印を出す(`report_html.py` の `_x_trend_badge`):
◎=positive かつ 値の飛び+3%未満 / ⚠=strong_positive / ⚠=値の飛び+3%以上(09:00以降のレポートのみ)。
表示する数字は固定値なので、件数が増えたら検証し直して更新する。
→ 2026-11-06: 5分足48営業日では、材料系で値の飛び+3%未満でも9:00買い→引け51%(平均-0.90%)と優位性が消えている。
  目印の付け方は変えないが、◎は「買ってよい」ではなく「⚠よりはまし」程度に読む(詳細は売買タイミングの節)

## 売買タイミングの目安(2026-10-06〜)

ユーザーの売買パターン(朝イチで買って10時までに売る/15時までに売る)に合わせて、
1時間足で検証した(2026-08〜10の48営業日、30日レンジ候補708件+Xトレンド銘柄237件。
寄り付き=9時台の始値、10時=9時台の終値、15時=14時台の終値で代用)。

- 寄り付き直後の1時間は弱い。どの種類も10時時点のプラスは5割未満になりがち
- ほとんどの種類で「10時で売る」より「15時まで持つ」方が成績がよい
- 寄り付きで買った場合、10時にプラスなら79%がプラスのまま15時に終わる(Xの材料系は94%)。
  10時にマイナスなら15時にプラスへ戻るのは25%(煽り系はさらに下げる)
- 10時に買う→15時は、寄り付きで買う→15時よりよい(全体55% vs 49%、モメンタム57% vs 48%)。
  ただし日経平均に勝った割合は約50%で、相場全体の後場の戻り(日経平均の10時→15時は平均+0.15%)が大きい。
  日経平均が最初の1時間で0.5%以上下げた日は、15日中11日で15時までに戻した
- Xの材料系(positive)は寄り付きで買う方がよい(65% vs 10時買い62%)。
  煽り系・寄り付きで+3%以上値が飛んだ銘柄は、どのタイミングでも優位性なし

買う時刻は15分足でも比較した(8/10〜10/6の38営業日・703件、9:00〜12:30の8通り×15時売り):
- 寄り付きちょうど(9:00)はモメンタム型(48%)と煽り系(39%、平均-0.55%)で最も不利。
  15分待つだけで改善する(全体50%→53%、煽り系の損失-0.55%→-0.19%)
- 9:15〜10:00の間に大きな差はない(9:45が特別よいわけではない)。モメンタム型は10:00が最良(54%)
- Xの材料系は9:00が最良(67%、平均+0.98%)で、待つほど利幅が減る(11:00買いは+0.38%)
- 煽り系はどの時刻に買っても41〜48%で勝てない

レポートの30日レンジ欄とXトレンド欄に「売買タイミングの目安」として表示する(数字は固定値)。
上げ相場の約2か月分のデータなので、下げ相場の期間を含めて見直す。

### 2026-11-06の見直し(5分足、2026-08-25〜11-05の48営業日)

保存した5分足(`state/intraday_archive/`)で計算し直した。下げ・横ばいの日が多い期間で、上の数字の多くは成り立たなかった。
レポートの表示(`report_html.py` の `RANGE_TIMING_GUIDE` / `X_TIMING_GUIDE`)もこの数字に差し替えた。
- 30日レンジの候補(10/6〜、111件): どの時刻に買っても引けでプラスは3〜4割(モメンタム36〜48%、リバーサル29〜41%)
- 寄りで買い、10時にプラス → 引けもプラス: リバーサル74%・モメンタム55%・注目銘柄79%。10時マイナス → 戻るのは15〜29%
- 注目銘柄(433件): 下げの朝(日経平均の寄り-0.5%以下)の寄り〜10時買い→引けが61〜66%。平らな朝は46〜47%
- 午前の終わり(11:30)に前日比プラス → 引けもプラス 86%、マイナス → プラスに戻る 13%(注目+保有、1,934件)
- Xの◎材料系: 9:00買い→引け 49%(平均-0.99%、68件)。以前の66〜67%から大きく悪化。上げの朝の10時買いだけ59%(17件)
- Xの⚠煽り系: どの時刻・どの朝でも18〜37%、平均-0.9〜-4.0%。寄りで+3%以上飛んだものは平均-4.6%
- 日経平均が寄り→10時で-0.5%以下の日: 16日中10日で引けまでに戻した(その日の10時買い→引け 54%)

## 振り返り(考察)に使うログ(2026-10-07〜)

朝・昼の判断を夕方に答え合わせできるよう、次が残る:
| 内容 | 場所 | 保存期間 |
|---|---|---|
| 送ったレポートそのもの(07:00/12:15/17:30/23:00。09:30は2026-10-18に廃止) | `output/history/reports/report_YYYYMMDD_HHMM.html` | 120日 |
| 30日レンジの候補一覧(06:45算出、時間外の値と取得元を含む) | `output/history/stock_range/stock_range_YYYYMMDD.json` | 120日 |
| Xトレンドの一覧(07:00・23:00の実行ごと) | `output/history/stock_x_trends_runs/stock_x_trends_YYYYMMDD_HHMM.json` | 無期限 |
| 30日レンジ候補の的中・当日の地合い(10/22からは寄り付きの値の飛び・寄り→引けも) | `state/stock_range_predictions.json` | 90日 |
| 毎営業日の地合い(候補がない日も) | `state/market_day_log.json`(2026-10-14〜) | 400日 |
| 5分足(指数・注目銘柄・保有銘柄・候補・Xトレンド銘柄) | `state/intraday_archive/YYYY-MM-DD.json.gz`(17:30、2026-08-25〜) | 無期限 |
| Xトレンド銘柄の的中 | `state/stock_x_trends_predictions.json` | - |
| 自分用の考察メモ | `trade_notes/`(git管理外) | - |
| 売買考察(自動) | `trade_notes/YYYY-MM-DD_1800_振り返り.txt`(10/13までは `_0800`・`_0945`・`_1300` もあり) | - |
| 売買考察のデータ(集めた数字・メール文・ログ文、実行ごと) | `output/history/trade_review/YYYYMMDD_HHMM_<時間帯>.json`(+ `_prompt.txt`) | 120日 |
| 寄りで+3%以上値が飛んだXトレンド銘柄の記録 | `state/trade_review_gap_log.json`(夕方の考察が毎日追記) | - |

売買考察は `modules/trade_review.py`(データと考察を `output/trade_review.json` に保存)と
`modules/trade_review_mail.py`(そのJSONを読んでメール)が営業日の18:00(夕方)に自動で書いてメールする
(2026-10-08〜。10/13までは08:00・09:45・13:00も。2026-10-15〜は注目銘柄と保有銘柄が主役、祝日は休み)。数字は Python が集め、文章は Claude(`claude -p`)。このルールファイルをそのまま判断基準として渡すので、
ルールを更新すれば考察も追従する。書き方・観点は `prompts/trade_review/`(common.md と evening.md。朝・寄り付き後・昼のファイルは今は使っていない)で直す。

※ `output/stock_x_trends.json` は23:00に翌日向けの一覧へ置き換わるので、その日の朝の一覧は
  `stock_x_trends_runs/` の `_0700` を見る。
