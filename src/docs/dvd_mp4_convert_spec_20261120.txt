DVD(VIDEO_TS)→MP4 変換バッチ 仕様書
作成日: 2026-11-20
状態: 仕様合意済み・未実装（実装開始はユーザーの号令待ち）
参考: flac_aac_mirror_spec_20261120.txt

■ 目的
外付けHDD上の DVD 取り込みフォルダを HandBrakeCLI で MP4 に変換する。
DVD 1枚（作品）につき MP4 1本を作り、夜間バッチで少しずつ進める。

■ 対象フォルダ（2026-11-20 時点の調査）
ベース: E:\data@T1TBEXFAT\non_syncthing\【dvd】\
  - dvd_anime_2022   24枚
  - dvd_music_2022    2枚
  - dvd_music_2026   10枚
  合計 36枚（【dvd】全体は 142GB。下記の対象外を含む）
対象外: 削除OK_dvd_other_2022（3枚。FLAC側の【削除OK】と同じ扱い）

元の構成: 【dvd】\<元フォルダ名>\<DVD名>\VIDEO_TS\*.VOB / *.IFO / *.BUP

■ 変換の単位（重要）
VOB ファイル単位ではなく、DVD 作品単位（VIDEO_TS フォルダ＝DVD 1枚）で変換する。
  - 長いライブなどで映像が複数の VOB にまたがっていても、つなげて1本の MP4 にする
    （VTS_01_1.VOB〜VTS_01_4.VOB は 1GB ごとに分割された「1本の映像」）
  - VTS_xx_0.VOB / VIDEO_TS.VOB はメニュー映像なので使わない
  - HandBrakeCLI に VIDEO_TS フォルダを渡すと DVD として読み込み、VOB を順につないで扱う。
    VOB を個別に変換したり、手でつなげたりする処理は作らない

■ 変換するタイトル
本編だけを変換する（HandBrakeCLI の --main-feature）。DVD 1枚につき MP4 1本。
注意: 話ごと・前半後半などで本編が複数のタイトルに分かれている DVD では、
      一部しか変換されないおそれがある。導入時の全 DVD スキャンで
      「本編以外にも長いタイトルがある DVD」を一覧にし、扱いを相談して決める。

■ 出力先
【dvd】\mp4\<元フォルダ名>\<DVD名>.mp4
DVD ごとのフォルダは作らない。DVD のフォルダ名をそのまま MP4 のファイル名にする。

  【dvd】\mp4\
    dvd_anime_2022\
      KASIMASI_01.mp4
      KASIMASI_02.mp4
      君たちはどう生きるか.mp4
      …
    dvd_music_2022\
      BON-BON BLANCO_女祭.mp4
      …
    dvd_music_2026\
      ダブル・ドラム・パフォーマンス.mp4
      …

.DS_Store / IFO / BUP などはコピーしない。

■ 変換設定（標準のおすすめ設定）
- ツール: HandBrakeCLI 1.11.2（winget install --id HandBrake.HandBrake.CLI -e で導入。
  いま入っているのは GUI 版のみで、バッチからは使えない）
- 映像: H.264（エンコーダーは x264）、画質固定 RF 20、解像度は元のまま、インターレース解除あり
- 音声: AAC 256kbps（すべての音声トラック）
- 字幕: DVD の字幕トラックをすべて MP4 に入れる（表示はオフ）
- チャプター: 引き継ぐ（ライブの曲ごとの頭出しなどが使える）

■ 所要時間の見込み
CPU が Core i5-6300U（2コア4スレッド）なので重い。
x264 で全部終わるまで 夜7時間×3〜4晩程度の見込み（本編だけなので、これより短くなる可能性あり）。
→ 1晩で終わらない前提で、続きから再開できる作りにする。

■ 夜間の動き
- 毎晩 23:30 開始。06:00 を過ぎたら新しい DVD には着手しない
  （変換中のものは最後まで続ける。途中で止まったものは翌晩にやり直す）
- 変換済み（MP4 がある）DVD は飛ばす → 新しく DVD を取り込むと、その晩に自動で変換される
- 全部終わったあとは、毎晩のチェックは数秒で終わる
- 既存の config.json のスケジュールの仕組みに乗せる（中身は Python、起動は .bat）
  ※日本語のフォルダ名が多いため、処理そのものを .bat で書くと文字化けなどで壊れやすい

■ 同期のルール（FLAC より単純）
- 追加: DVD フォルダあり / MP4 なし → 変換
- 削除: 元の DVD を消しても MP4 は消さない（作り直しに時間がかかるため）。
  元がない MP4 はメールで知らせるだけ

■ 安全策（FLAC と同じ考え方）
- 目印ファイル: 元フォルダごとに .dvd_root を置き、あるフォルダだけを処理する
  （外付けHDDはドライブ文字が変わることがあるため）
- HDD が見つからない / 目印ファイルがない: 何もせずメールで通知
- 書きかけ対策: .tmp.mp4 に書き出し、完了してから正式な名前に変える
- 二重起動の防止: ロックファイル
- 元の DVD フォルダには一切書き込まない（読み取りのみ）

■ 通知（既存の modules/mail_gmail.py）
- 変換した夜だけ送る。本文に件数（完了 / 失敗 / 残り）と、失敗した DVD の一覧
- HDD なしなどのスキップ時は、変換0件でも通知する
- 05:00〜05:15 は回線が切れるので、メールはその時間を避ける

■ 導入の手順（実装時）
1. HandBrakeCLI をインストール
2. 3つの元フォルダに .dvd_root を置く
3. 全 DVD をスキャンして、タイトル一覧（長さ）をメールで確認
   → 本編が複数タイトルに分かれている DVD の扱いを決める
4. 1枚だけ試しに変換して、画質・サイズ・速度を確認
5. 毎晩のスケジュールに登録

■ Q&A（2026-11-20 のやりとりの記録）

Q1. どの映像（タイトル）を変換するか
    - 案A: 3分以上のタイトルをすべて変換する
    - 案B: 本編だけ（--main-feature）
    回答: 案B 本編だけ。
    補足: 本編が複数タイトルに分かれている DVD がないかは、導入時のスキャンで確認する。

Q2. 出力先の構成
    最初の案: 【dvd】\mp4\<元フォルダ名>\<DVD名>\<DVD名>_t01.mp4
    回答: DVD 単位で MP4 ができればよいので、DVD ごとのフォルダは不要。
          【dvd】\mp4\<元フォルダ名>\<DVD名>.mp4 のように MP4 が並ぶほうが探しやすい。
    補足: dvd_anime_2022 などの元フォルダの階層は残す（アニメと音楽を分けるため）。
          これもなくして mp4\ の直下に全部並べたい場合は、実装時に変更する。

Q3. 削除OK_dvd_other_2022 を対象から外してよいか
    回答: OK（対象から外す）

Q4. 画質を優先するか、速さを優先するか
    - 案A: 画質優先（x264）… 3〜4晩くらい
    - 案B: 速さ優先（Intel QSV）… 1〜2晩くらい。同じファイルサイズなら画質が落ちる
    回答: 標準のおすすめで（案A x264）。
    補足: H.264 は動画の形式の名前、x264 は H.264 を作るソフトの名前。
          x264 で作ったファイルは昔と同じ H.264 の MP4 で、ほとんどの機器で再生できる。

Q5. 変換の単位
    回答: VOB 単位ではなく DVD 作品単位にする。長いライブなどは VOB の途中で
          映像が切れているかもしれないため。
    補足: 最初からこの方式で設計済み。HandBrake が VOB をつないで1本の MP4 にする。
