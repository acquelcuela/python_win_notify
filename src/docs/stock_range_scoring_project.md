# 30日レンジ予想スコアリング 考察・改善プロジェクト

## 目的

`stock_range` が出す「翌営業日 上昇候補」(モメンタム型・リバーサル型の2パターン)の
スコアリングが実際にどれくらい当たっているかを継続的に検証し、根拠のある範囲で
ロジックを改善していく。

## 現在のアーキテクチャ(2026-07-31時点)

データ生成とメール送信(HTML化)を分離した4モジュール構成:

| モジュール | 役割 | 実行タイミング |
|---|---|---|
| `stock_range.py` | スコア計算・`output/stock_range.json`にフルデータ出力 | 06:45 / 21:30 |
| `stock_range_mail.py` | `stock_range.json`を読んでHTML化・メール送信 | 06:45 / 21:30 |
| `stock_range_eval.py` | 当日ログ済み候補をyfinanceで再取得し的中判定・`output/stock_range_eval.json`に出力 | 17:00 |
| `stock_range_eval_mail.py` | `stock_range_eval.json`を読んでHTML化・メール送信 | 17:00 |

考察用の永続ログは `state/stock_range_predictions.json`(90日保持)。各レコードには
以下が入る:

- `logged_date` / `evaluated_date` / `type`(momentum/reversal) / `ticker` / `score` / `reasons`
- `position_pct` / `trend` / `trend_change_pct` / `x_trend_sentiment` / `market_change_pct`
  (ロギング時点のスコア内訳の数値。2026-07-31以降に追加したレコードから入っている。
  それ以前のレコードにはこれらのフィールドは無い)
- `hit` / `actual_change_pct`(判定結果)

## これまでの考察結果

### 2026-07-27〜07-31(評価済み97件、5取引日分)

- モメンタム型: 的中率57%前後だが平均実現リターンはマイナス。勝ちが小さく負けが
  大きい非対称の疑いがある。レンジ位置がほぼ100%(既に高値圏)の銘柄ほど外れやすい
  傾向が07-31分で見えた。
- リバーサル型: 的中率・平均リターンともに現状マイナス。夜間先物が大きく崩れた日
  (07-28)は0/9で全滅、逆に大きく上げた日(07-31, 先物+2.52%)は10/10全勝(値幅も
  +5%〜+18%と大きい)。銘柄選定というより地合いに強く引っ張られている疑いが強い。
- 日ごとのブレが非常に大きい(モメンタム25%〜88%、リバーサル0%〜100%)。評価対象が
  まだ5取引日分しかなく、統計的な結論を出すには全く足りない。

### 2026-08-05更新(評価済み123件、07-27〜08-04の9取引日分)

- 全体の的中率はモメンタム50.8%(31/61)、リバーサル50.0%(31/62)とほぼコイン投げ
  水準に収束。平均実現リターンもモメンタム-0.12%、リバーサル-0.27%とほぼゼロ〜
  わずかにマイナス。07-31時点で見えていた「57%/地合い連動」は日数を増やしたら
  平均化して消えた。
- スコア帯別の的中率も、以前は緩やかな右肩上がりに見えたが(モメンタム40点台36%→
  70点台73%)、08-03・08-04を加えると40点台50%、50点台38%、60点台56%、70点台55%と
  フラットに近づき、スコアが高いほど当たるという傾向は今のところ確認できない。
- market_change_pctの符号でも明確な傾向は出ていない(08-03は先物-0.99%で両型とも
  1桁%の的中率、08-04は先物-0.34%とほぼ同水準の下落なのに両型とも好調)。符号だけ
  では説明できない。
- 依然として日ごとのブレが大きい(08-03はモメンタム17%・リバーサル14%、08-04は
  モメンタム60%・リバーサル100%)。

## 現時点の結論

**まだロジックを変える段階ではない。** 9取引日まで増えても、的中率・平均リターン
ともにコイン投げと有意な差がない(≒現状のルールベーススコアには edge が確認できて
いない)。地合いの符号だけでも説明がつかず、単純な閾値調整では改善しない可能性が
高い。しばらくはロジックを変えずにログを溜め続け、最低でも数週間〜1か月分のデータ
(特に平常日を多く含む状態)で再評価するのが良い。
