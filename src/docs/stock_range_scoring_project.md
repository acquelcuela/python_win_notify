# 30日レンジ予想スコアリング 考察・改善プロジェクト

## 目的

`stock_range` が出す「翌営業日 上昇候補」(モメンタム型・リバーサル型の2パターン)の
スコアリングが実際にどれくらい当たっているかを継続的に検証し、根拠のある範囲で
ロジックを改善していく。

## 現在のアーキテクチャ(2026-08-11更新)

データ生成とメール送信(HTML化)を分離した構成。`stock_range_eval_mail.py`は
2026-08-11に廃止し、当日の的中結果はメインレポート(`report_html.py`)の
セクションとして表示する形に統合した(17:00単独メール・21:30の夜間版メールも
廃止):

| モジュール | 役割 | 実行タイミング |
|---|---|---|
| `stock_range.py` | スコア計算・`output/stock_range.json`にフルデータ出力(日本株限定) | 06:45 |
| `stock_range_mail.py` | `stock_range.json`を読んでHTML化・メール送信(レンジ位置カードのみ、スコア欄なし) | 06:45 |
| `stock_range_eval.py` | 当日ログ済み候補をyfinanceで再取得し的中判定・`output/stock_range_eval.json`に出力 | 22:45 |
| `report_html.py` | `stock_range.json`のスコア欄と`stock_range_eval.json`の的中結果をメインレポートに統合表示 | 07:00 / 09:30 / 12:15 / 22:45(的中結果は22:45分のみ当日データがあれば表示) |

考察用の永続ログは `state/stock_range_predictions.json`(90日保持)。各レコードには
以下が入る:

- `logged_date` / `evaluated_date` / `type`(momentum/reversal) / `ticker` / `score` / `reasons`
- `position_pct` / `trend` / `trend_change_pct` / `x_trend_sentiment` / `market_change_pct`
  (ロギング時点のスコア内訳の数値。2026-07-31以降に追加したレコードから入っている。
  それ以前のレコードにはこれらのフィールドは無い)
- `hit` / `actual_change_pct`(判定結果)

## これまでの考察結果

### 2026-07-27〜07-31(評価済み97件、5取引日分)

- モメンタム型: 的中率57%前後だが平均実現リターンはマイナス。勝ちが小さく負けが
  大きい非対称の疑いがある。レンジ位置がほぼ100%(既に高値圏)の銘柄ほど外れやすい
  傾向が07-31分で見えた。
- リバーサル型: 的中率・平均リターンともに現状マイナス。夜間先物が大きく崩れた日
  (07-28)は0/9で全滅、逆に大きく上げた日(07-31, 先物+2.52%)は10/10全勝(値幅も
  +5%〜+18%と大きい)。銘柄選定というより地合いに強く引っ張られている疑いが強い。
- 日ごとのブレが非常に大きい(モメンタム25%〜88%、リバーサル0%〜100%)。評価対象が
  まだ5取引日分しかなく、統計的な結論を出すには全く足りない。

### 2026-08-05更新(評価済み123件、07-27〜08-04の9取引日分)

- 全体の的中率はモメンタム50.8%(31/61)、リバーサル50.0%(31/62)とほぼコイン投げ
  水準に収束。平均実現リターンもモメンタム-0.12%、リバーサル-0.27%とほぼゼロ〜
  わずかにマイナス。07-31時点で見えていた「57%/地合い連動」は日数を増やしたら
  平均化して消えた。
- スコア帯別の的中率も、以前は緩やかな右肩上がりに見えたが(モメンタム40点台36%→
  70点台73%)、08-03・08-04を加えると40点台50%、50点台38%、60点台56%、70点台55%と
  フラットに近づき、スコアが高いほど当たるという傾向は今のところ確認できない。
- market_change_pctの符号でも明確な傾向は出ていない(08-03は先物-0.99%で両型とも
  1桁%の的中率、08-04は先物-0.34%とほぼ同水準の下落なのに両型とも好調)。符号だけ
  では説明できない。
- 依然として日ごとのブレが大きい(08-03はモメンタム17%・リバーサル14%、08-04は
  モメンタム60%・リバーサル100%)。

### 2026-08-11更新(評価済み217件、07-27〜08-10の12取引日分)

- 全体の的中率: モメンタム型54.0%(74/137)・平均リターン+0.72%。リバーサル型
  48.8%(39/80)・平均リターン-0.31%。モメンタム型は初めて平均リターンが明確に
  プラスへ転じた(08-05時点+0.47% → 今回+0.72%)。
- レンジ位置(position_pct)帯別のモメンタム型的中率は、70%未満59%/+1.70%、
  70〜90%17%/-0.97%(n=12)、90%以上58%/+1.11%で、「高すぎる銘柄ほど不利」と
  いう単純な傾向は確認できなかった(70〜90%帯が一番悪いのはむしろ逆で、
  サンプルが少なく(n=12)ノイズの可能性が高い)。
- **market_change_pctとの相関がサンプル増加後も一貫して残っている**(138件、
  2026-07-31以降のレコードのみ対象):
  - モメンタム型: 地合いプラスの日60%的中/+2.31%、マイナスの日44%的中/-0.39%
  - リバーサル型: 地合いプラスの日76%的中/+5.28%、マイナスの日41%的中/-0.50%
  - 07-31時点では「サンプルが少ないから偶然では」と疑っていたが、n=17〜55まで
    増えても同方向の差が残っているため、そろそろ偶然とは言い切れない。

## 実施した改善(2026-08-11)

market_change_pctとの相関が最も根拠が強かったため、`_market_penalty`(下落日のみ
減点)を `_market_adjustment`(上昇日は加点・下落日は減点の対称ロジック)に変更。
係数はこれまでの減点係数をそのまま流用(モメンタム factor=4/cap=30、リバーサル
factor=8/cap=50)。レンジ位置の中盤フィルタ案(70〜90%帯を除外する等)は、根拠が
n=12と弱いため見送り、`position_pct`は引き続きログに残して観察を続ける。

## 現時点の結論

地合い連動の加点/減点ロジックを入れたので、次回以降のログでこの変更が実際に
的中率・平均リターンを改善しているか(特にマイナス地合いの日の損失を抑えられて
いるか)を継続してチェックする。レンジ位置帯による絞り込みは、まだ根拠不足のため
保留のまま。

今後の具体的な取り組みは `stock_range_scoring_todo.txt` を参照。
