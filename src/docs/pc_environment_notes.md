# このPCの環境メモ

バッチ(タスクスケジューラ)の時刻や、失敗の原因を考えるときに見返すメモ。

## 毎日 05:00〜05:15 はインターネットにつながらない(2026-10-14 記録、10-15 更新)

- 外側のルータ(ONUにつながっているルータ)が、毎日リセットされる
  - 05:00 に電源OFF、05:05 に電源ON
  - 起動に数分かかるので、つながるのは 05:10 ごろの見込み
  - 余裕を見て 05:00〜05:15 を「つながらない時間」として扱う
- このPCがつながっているルータは止まらない
  - 家の中のネットワーク(LAN)は生きている
  - インターネットにだけ出られない

```
[このPC] ── [自分のルータ] ── [外側のルータ] ── [ONU] ── インターネット
                 ↑ 止まらない       ↑ 05:00 OFF → 05:05 ON(起動に数分)
```

### バッチへの影響
- この時間にネットを使う処理は失敗する
  - Webの取得(株価・ニュース・ヤフオクなど)
  - Gmailの送信
  - Claude / Gemini の呼び出し
- 失敗は「ネットワークがない」ではなく、名前解決のエラーやタイムアウトとして出るはず
- PCの中だけで終わる処理(ファイルの整理など)は問題ない

### スケジュールを決めるときの決まり
- 05:00〜05:15 にネットを使う処理を入れない
  - 復旧を待つ余裕をとって、05:30以降にする
- 05:00ごろに失敗したら、まずこれを疑う
- 現状、この時間にかかるのは 05:00 の post_x_magazine だけ
  - 2026-10-14時点では止めてある
  - 再開するときは 05:30以降にずらす
