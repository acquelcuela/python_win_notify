# 夕方(18:00)の考察

時間帯の名前は「夕方(1日の振り返り)」。15時の値と終値で、朝・昼の考察とルールを答え合わせする。

## 主役は「注目銘柄」と「保有銘柄」(2026-10-15〜)
夕方の考察は、注目銘柄(stock_range.watchlist、特別注目を含む)と保有銘柄(holdings)を主役にする。
Xトレンド銘柄と30日レンジの候補は「参考」として短くまとめる。

### メールのパートの並び(共通の指示の「メールのパート」より、こちらを優先)
■ ひとことで(2〜3行。地合いと、注目銘柄・保有銘柄がどうだったか)

■ 注目銘柄
  stock_range.watchlist の全銘柄を1銘柄1ブロックで(共通の指示の「銘柄ごと」と同じ形: 想定/結果/よかった買い方/ひとこと)。
  特別注目(candidates の special_watch が true)や今日の30日レンジの候補に入った銘柄を先に。◆の行に ⭐特別注目 などの印を付ける。
  保有銘柄にも入っている銘柄(holdings の also_in_watchlist)は ◆の行に「(保有)」と付ける。

■ 保有銘柄
  1行目に、全体のまとめを1〜2行(holdings_summary: 何銘柄中いくつ上がった・下がった、平均、日経平均と比べてどうか)。
  次の行に、次の1行だけを文字どおり書く(メールで全銘柄の表に置き換わる):
  [保有銘柄の表]
  そのあと、目立った保有銘柄だけを3〜6銘柄、1銘柄2〜3行で:
  ◆ 銘柄名(コード)
    結果: 前日比 / 寄り付きの値の飛び / 寄り→15時 / 30日レンジの位置 / 5日の値動き を「ラベル 値 / ラベル 値」の形で1行
    ひとこと: なぜ目立ったか(大きく動いた、30日の高値・安値の近く、日経平均と逆の動き など)をやさしく1〜2行
  選び方: holdings_summary の big_movers_3pct(±3%以上)を優先し、near_30d_high / near_30d_low から補う。
  表にすべて載るので、それ以外の銘柄の数字を文章で繰り返さない。

■ 参考: Xトレンド・30日レンジの候補
  1銘柄1行で短く(「名前(コード): 前日比 / 寄り買い→15時 / ルールどおりなら見送り・買い」程度)。ルールの当たり外れを1〜2行。

■ 今日のおさらい / ■ 勉強メモ(共通の指示どおり)

ログのパートは今までどおり全部をくわしく書く。ただし「■ 保有銘柄」の節を ■ 注目銘柄 の次に足し、
全銘柄を1銘柄1行(名前(コード): 前日比 / 寄り付きの値の飛び / 寄り→15時 / 30日レンジの位置 / 5日の値動き)で残す。

## 書くこと
(以下は主にログのパートに書く内容。メールのパートは共通の指示の「メールのパート」に従い、同じ内容をやさしい言葉で短くまとめる)
- ■ 地合い: 日経平均・TOPIXの前日比(終値)、当日の地合いの判定(両方上昇/まちまち/両方下落、market_day_recorded)、
  朝の時間外の動きの見立てが当たったか、後場の戻り(10時→15時)があったか
- ■ 銘柄ごと: 「想定」は朝の考察から引き継ぐ(昼の考察で想定が変わっていればそれも)。
  朝・昼の考察がない日(2026-10-14以降は夕方の1回だけが基本)は、朝のデータ(30日レンジの候補・Xトレンド・注目銘柄と
  ルールファイル)から「朝の時点でルールどおりなら、どう動くはずだったか」を想定として書く。
  「結果」は 寄り付きの値の飛び / 寄り→10時 / 寄り買い→15時 / 10時チェック適用 / 9:15買い→15時 / 10時買い→15時 / 前日比(終値)
  ※10時チェック適用 = 寄りで買い、10時にプラスなら15時まで持ち、マイナスなら10時で売った場合
  「考察」には、想定どおりだったか、なぜそうなったか、次に活かすこと
- ■ ルールごとの答え合わせ(✅/❌/1勝1敗 などで一目で分かるように):
  1. 30日レンジ: 寄り付きで買う vs 10時に買う(→15時売り)。候補全体の平均と、プラスだった数
  2. 寄りで+3%以上値が飛んだ銘柄の見送り(big_gap_x_stocks_history で過去分を含めて何件中何勝、勝ち負けの大きさ)
  3. ⚠煽り系の見送り
  4. ◎材料系の朝イチ買い
  5. 寄りで買って10時にプラスなら15時まで持つ / マイナスなら10時で売る
- ■ 今日の学び: ルールが効いた点・効かなかった点、検証する価値のある新しいルールの候補
