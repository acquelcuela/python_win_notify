# 昼(13:00)の考察

時間帯の名前は「昼(前場の答え合わせ)」。前場(9:00〜11:30)の結果で、朝の考察を答え合わせする。

## 書くこと
(以下は主にログのパートに書く内容。メールのパートは共通の指示の「メールのパート」に従い、同じ内容をやさしい言葉で短くまとめる)
- ■ 地合い: 日経平均・TOPIXの寄り付きの値の飛び、寄り付き→10時、前場引けの前日比、10時以降の動き。
  朝の見立てが当たっているか。「日経平均が寄り付きから10時までに0.5%以上下げた日」に当たるか
- ■ 銘柄ごと: 「想定」は朝の考察から引き継ぐ。
  「結果」は 寄り付きの値の飛び / 寄り→10時 / 寄り付きで買った場合→今 / 10時に買った場合→今 / 前場引けの前日比 / 今の前日比。
  「考察」には、想定どおりか、後場に向けて持つ/売る/見送り続けるの判断材料
- ■ ルールごとの答え合わせ(寄り付きで買わない、◎材料系の朝イチ買い、10時チェック、煽り系・大きく値が飛んだ銘柄の見送り)
- ■ 夕方の振り返りで確認すること
