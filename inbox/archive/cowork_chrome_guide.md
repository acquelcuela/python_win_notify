# Cowork × Chrome × Grok 自動化ガイド

---

## やりたいこと

```
Coworkに指示するだけで：

① Chrome で x.com を開く
② Grok で検索ワードを入力・実行
③ 結果画面のスクリーンショットを撮る
④ ファイルに保存する

→ この一連の流れを自動実行
```

---

## 最新動向（2026年8月）

<cite index="2-1">Claude in ChromeのサイドパネルがフルCoworkセッションになり、スクリーンショット・マウス操作・テキスト入力が可能になった（2026年8月12日更新）。</cite>

<cite index="3-1">CoworkのComputer Use機能はリサーチプレビューとしてPro/Maxプランで利用可能。スクリーンショット取得・マウスクリック・テキスト入力が可能で、Claudeはログイン済みのサイトで直接操作できる。</cite>

---

## 実現可能性：✅ できる

| 操作 | 可否 |
|---|---|
| Chromeを起動・操作 | ✅ |
| x.com を開く | ✅（ログイン済みであれば） |
| Grokに検索ワードを入力 | ✅ |
| スクリーンショットを撮る | ✅ |
| ファイルに保存する | ✅ |

---

## 必要な条件

| 条件 | 内容 |
|---|---|
| **Claudeのプラン** | **Pro以上**（リサーチプレビュー） |
| **アプリ** | Cowork デスクトップアプリ（macOS / Windows） |
| **ブラウザ** | Chrome（Chromiumベースの他ブラウザは非対応） |
| **Xへのログイン** | Chromeであらかじめ x.com にログイン済みであること |
| **Computer Use設定** | Coworkの設定でONにする必要あり |

## 使い方

### Step 1：Cowork デスクトップアプリをインストール

```
claude.ai/download からダウンロード
→ macOS または Windows 版をインストール
```

### Step 2：Computer Use をONにする

```
Coworkを開く
→ 設定（⚙）
→「コンピュータ使用」をONにする
```

### Step 3：Claudeに日本語で指示するだけ

```
指示例：

「Chromeでx.comを開いて、
 Grokで『生成AI 最新ニュース』を検索して、
 結果が表示された画面のスクリーンショットを
 デスクトップに保存して」

        ↓ Coworkが自動実行

① Chromeを起動
② x.com/i/grok を開く（ログイン済みアカウントで）
③ 検索ワードを入力・実行
④ 結果画面でスクリーンショット取得
⑤ 指定場所にファイル保存
```

---

## 仕組み

<cite index="4-1">Claude in Chromeの土台にはAnthropicが開発した「Computer use」という技術が使われており、AIがマウスやキーボードを操作できるようにする技術。画面のスクリーンショットを撮って内容を認識→マウスでクリック→テキスト入力という操作をClaudeが自律的に判断しながら実行する。</cite>

```
Cowork
  ↓ スクリーンショットで画面を認識
  ↓ マウスでクリック
  ↓ キーボードで入力
  ↓ 結果をスクリーンショット
  ↓ ファイル保存
```

---

## 注意点

| 項目 | 内容 |
|---|---|
| **リサーチプレビュー** | まだ実験的機能。動作が不安定な場面もある |
| **プロンプトインジェクション** | ウェブサイト上の隠し指示をClaudeが受け取るリスクがある |
| **重要操作の確認** | 重要なアクション前にClaudeが確認を求める設定を推奨 |
| **ログイン状態** | Chromeで事前にXにログインしていることが前提 |
| **Chrome限定** | ChromiumベースのEdge等は非対応（Chrome本体のみ） |

## 活用アイデア

```
① Grok検索 → スクリーンショット → 定期保存
   「毎朝9時にGrokで〇〇を検索して結果を保存」

② Grok検索 → 内容をClaudeが要約 → テキストファイルに保存
   「検索結果をまとめてmarkdownで保存して」

③ 複数キーワードを順番に検索してまとめてキャプチャ
   「A・B・C の3ワードをそれぞれ検索して
    全部スクリーンショットを撮って」
```
