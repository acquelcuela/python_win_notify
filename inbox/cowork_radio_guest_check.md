# Cowork向け指示: radiko・NHK FM・音泉 番組ゲスト情報まとめ

Coworkに貼り付けて実行してもらう用の指示文。実行のたびにこのファイルの
内容をコピペして渡す(スケジュール化はしない、都度手動でGoする運用)。

---

## Coworkへの指示文(このままコピペ)

```
ChromeでX(x.com)を開き、Grok(x.com/i/grok)を使って、以下3つの
ラジオ・音声配信サービスの本日の番組ゲスト情報を検索してください。

対象サービス:
1. radiko
2. NHK FM
3. 音泉

やってほしいこと:
1. x.com/i/grok を開く
2. サービスごとに、以下のような検索を行う(例):
   - 「radiko 本日 番組表 ゲスト」
   - 「NHK FM 本日 番組 ゲスト出演」
   - 「音泉 本日 番組 ゲスト」
3. Grokの回答から、番組名・放送時間・ゲスト名が分かる情報を抜き出す
4. 情報が不足している場合は、検索語を変えて追加で検索してよい
5. 3サービス分の結果を、サービスごとに見出しを分けて
   「番組名 / 放送時間 / ゲスト名」の一覧としてまとめる
6. まとめた内容をテキストファイルとしてデスクトップに保存する
   (ファイル名: radio_guest_YYYYMMDD.txt、YYYYMMDDは本日日付)

キャプチャ(スクリーンショット)は必須ではありません。Grokの回答文から
テキストとして情報が取得できるなら、スクリーンショットより文字起こしを
優先してください。
```

---

## 補足メモ

- 検索テーマは毎回固定(radiko・NHK FM・音泉のゲスト情報)。指示文はこのまま
  使い回せる
- 保存先はひとまずデスクトップ想定。Coworkを実行するPC側でユーザーが
  コピペして持ち込む運用のため、python_win_notifyリポジトリとの連携は
  現時点では想定していない
- スクリーンショットより「テキストとして取得できるならそちらを優先」と
  明記している(検討経緯: inbox/cowork_chrome_guide.md参照)
